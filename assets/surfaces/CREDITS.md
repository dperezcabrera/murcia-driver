# Materiales del escenario

Poly Haven publica estos recursos bajo [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/). La [licencia de Poly Haven](https://polyhaven.com/license) cubre las texturas, los modelos 3D y el HDRI.

| Recurso | Autoría según Poly Haven | Uso en el juego |
| --- | --- | --- |
| [Asphalt 04](https://polyhaven.com/a/asphalt_04) | Jenelle van Heerden, Sergej Majboroda | Color del asfalto, convertido a WebP. |
| [Concrete Pavement 02](https://polyhaven.com/a/concrete_pavement_02) | Charlotte Baglioni | Losas de las aceras, convertidas a WebP. |
| [White Plaster 02](https://polyhaven.com/a/white_plaster_02) | Rob Tuytel | Textura base del atlas de fachadas hasta el dosier 27; el atlas actual ya no la usa. |
| [Wood Shutter](https://polyhaven.com/a/wood_shutter) | Dimitrios Savva | Carpintería del atlas de fachadas hasta el dosier 27; el atlas actual ya no la usa. |
| [Painted Metal Shutter](https://polyhaven.com/a/painted_metal_shutter) | Dario Barresi, Rico Cilliers, Charlotte Baglioni | Persianas y cierres del atlas de fachadas hasta el dosier 27; el atlas actual ya no la usa. |
| [Jacaranda Tree](https://polyhaven.com/a/jacaranda_tree) | Rob Tuytel, Rico Cilliers | Color y máscara de las hojas usados para componer dos copas de árbol. |
| [Venice Sunset](https://polyhaven.com/a/venice_sunset) | Greg Zaal | Iluminación de entorno y reflejos en los coches. |
| [Kloofendal 48d Partly Cloudy (Pure Sky)](https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky) | Greg Zaal, Jarod Guest | Panorama de cielo. |
| [Grass Ground](https://polyhaven.com/a/grass_ground) | Charlotte Baglioni | Vegetación baja en zonas verdes. |

Las fachadas y los árboles son composiciones propias. El atlas de fachadas (`facades.webp`) se dibuja entero con `docs/dosier/img/19/atlas.py`, sin imagen de partida. El HDRI se utiliza para iluminar la escena y reflejar el entorno en los materiales.
